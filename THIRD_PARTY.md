# Third-party scope

No npm dependencies, browser binaries, private browser profile or ChatGPT conversation database are vendored. `package-lock.json` records the development dependency graph. Installed package metadata observed during preparation lists TypeScript and Playwright under Apache-2.0, Vitest/esbuild/jsdom under MIT, and fake-indexeddb under Apache-2.0. These packages retain their own licenses when installed; this project does not relicense them.

The extension uses the user's existing ChatGPT session and its internal same-origin endpoints. OpenAI and ChatGPT names identify interoperability, not endorsement, ownership of provider code or a grant of service access. Microsoft Edge is an external runtime. The mock page and fixture records are test scaffolding. Original-project attribution or third-party notices, if later identified, must be retained before publication.
